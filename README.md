Student Task Study Planner

About

Student Task Study Planner is a web application that helps students organize their tasks and manage their study schedules.

Features

- Add and manage study tasks
- Organize academic activities
- Simple and user-friendly interface

Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite

How to Run

1. Install Python.
2. Install Flask using "pip install flask".
3. Run the application using "python app.py".
4. Open the local URL displayed in your terminal.
